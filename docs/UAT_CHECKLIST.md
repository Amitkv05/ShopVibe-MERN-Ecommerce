# Client UAT Checklist

## Customer flow
- Register, verify email and login
- Browse/search/filter/sort products
- Open product details and select variant/quantity
- Add/remove/update cart and wishlist
- Apply valid/invalid coupons
- Create/select address
- Complete COD checkout
- View order history/details and allowed cancellation
- Receive expected emails
- Razorpay test checkout/payment/refund after Test Mode is configured

## Admin flow
- Dashboard metrics
- Product/category CRUD
- Inventory adjustment and history
- Order Processing → Shipped → Delivered
- Customer and role administration
- Coupon lifecycle
- Review moderation
- Analytics, media and system diagnostics

Record each item as Pass / Defect / Change Request. Only defects in approved scope block sign-off; new requests should be separately approved and scheduled.
