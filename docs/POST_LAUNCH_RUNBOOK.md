# Post-Launch Runbook

During the first day and agreed support period:
- Watch API uptime/readiness and 5xx errors.
- Watch database connectivity/latency and Atlas alerts.
- Watch payment/webhook failures and duplicate events.
- Watch SMTP delivery failures.
- Review inventory discrepancies and failed order compensation events.
- Triage launch defects by severity and record fixes/redeployment evidence.
- Complete the agreed support period and hand over any open non-critical improvement backlog.
